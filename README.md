## 🚀 Запуск

Просто откройте `index.html` в браузере. Всё работает без сервера!

## ✨ Функционал

- ✅ Полностью адаптивный дизайн (до 320px)
- ✅ Горизонтальная навигация и футер
- ✅ Тёмная тема с сохранением
- ✅ Фильтры, поиск, сортировка товаров
- ✅ Корзина с localStorage
- ✅ Валидация форм
- ✅ Модальные окна и тосты
- ✅ 12+ сгенерированных SVG-изображений
- ✅ 50+ новых CSS-эффектов
- ✅ Анимации и hover-эффекты

## 🛠 Технологии

- HTML5 (семантика, BEM)
- CSS3 (Flexbox, Grid, анимации, переменные)
- Vanilla JS (ES6+, модули)
- LocalStorage
